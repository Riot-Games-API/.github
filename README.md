# 🎮 Riot Games API

Riot Games API is a **client library** for Riot's public endpoints. It wraps **key rotation**, **rate limit** handling, and **region routing** so calls stay inside quota.

## ✨ Key Features

- 🔑 **Key rotation** across methods
- 🚦 **Rate limit** backoff

- 📊 **Quota readout**
- 🧾 **Typed responses**
- 🪵 **Request logging**
- 🔁 **Retry policy** config

## 🚀 Why Choose Riot Games API?

Riot enforces per-method limits, and hand-rolled retries usually break them. The library tracks buckets and backs off before the ceiling is hit.

Region and product wrappers remove string building from every call.
